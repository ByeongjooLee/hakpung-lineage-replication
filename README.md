# 한국 현대문학 박사학위논문의 학맥·학풍 분석 — 재현 자료

심사 중인 논문의 부록 C(공개 파생표)와 부록 D(재현 절차)에 해당하는 자료다. 심사를 위해 논문 제목, 투고자, 자료를 공개한 사이트의 주소를 가렸다. 가린 곳은 `<SITE>`로 적혀 있으며 심사가 끝나면 채운다. 본문과 부록의 수치는 이 저장소의 표에서 다시 계산할 수 있다.

- 자료 기준일: 2026년 11월 22일 판 학맥(지도교수–제자 관계망)
- 분석 대상: 박사학위논문 1,434편 × 교수 298명(427,332쌍)

## 가장 짧은 재현 방법

비공개 자료 없이 이 저장소만으로 본문 표 3의 값을 다시 계산할 수 있다.

1. `data/derived_tables/pair_relations_similarity.csv.gz`를 연다. 한 행이 박사학위논문 한 편과 교수 한 명의 쌍이다.
2. 종속변수는 `resid_bge`(논문 평균과 교수 평균을 뺀 유사도), 설명변수는 `relation_all`의 관계 여섯 가지 더미와 `same_uni_x_lineage_all`이다.
3. 상수항 없이 최소제곱 회귀를 돌리면 `regression_results.csv`의 계수가 소수 일곱째 자리까지 같게 나온다.
4. `resid_bge` 대신 다른 `resid_*` 열을 쓰면 다른 측정 방법의 결과가, `relation_all` 대신 `relation_confirmed`를 쓰면 동일인 판정이 확정된 관계만 쓴 결과가 나온다.

`scripts/pipeline/lineage_robustness.py`는 이 폴더의 표만 입력으로 받아 계보 강건성 분석을 다시 돌린다.

## 들어 있지 않은 것

저작권과 개인정보 때문에 다음은 넣지 않았다.

- 박사학위논문 본문, 학술지 논문 초록, 그 임베딩 벡터와 낱말 빈도 캐시
- 논문 한 편 한 편의 토픽 비중(`thesis_topics_k50.csv`)
- 수집 과정의 원자료(KCI·국립중앙도서관 응답), API 키, 로컬 경로

따라서 임베딩부터 다시 하려면 KCI Open API와 국립중앙도서관 LOD에서 서지와 초록을 직접 받아야 한다. 절차는 논문 부록 D와 `scripts/pipeline/`의 스크립트에 있다. 스크립트 안의 경로는 `<PROJECT>`, `<HOME>` 같은 자리 표시로 바꾸어 두었으므로 자기 환경에 맞게 고쳐야 한다. API 키는 환경변수로만 받는다.

스크립트 셋(`student_trajectory.py`, `tfidf_topic_replication.py`, `embed_variants.py`)은 정리가 끝나지 않아 아직 넣지 못했다.

## 읽을 때 주의할 점

- 모든 수치는 수집한 자료 안에서 확인되는 관계만 센 값이다. 한국 현대문학 연구의 사제 관계 전체가 아니다.
- 학맥 자료는 2000년 이후가 촘촘하고 그 이전이 성기며, 서울대 쪽이 다른 대학보다 촘촘하다.
- 사람을 잇는 판정에는 '확정', '추론', '미확인'의 세 단계가 있다. 표에 단계가 적혀 있다.
- 닮음은 연구 주제의 닮음이며 연구의 수준에 대한 평가가 아니다.
- 표에는 교수와 학위자의 실명, 공개 서지 번호(RISS, KCI), 국립중앙도서관 전거 번호가 들어 있다. 모두 공개된 서지에서 온 것이다.
